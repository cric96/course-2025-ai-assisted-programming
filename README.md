# AI-assisted Programming

Repository per le slide del corso **AI-assisted Programming: come l'AI sta cambiando il modo di programmare**, con un focus pratico su **GitHub Copilot** e sugli strumenti moderni di sviluppo assistito.

## Contenuti

- concetti di base di *AI-assisted programming* e casi d’uso reali;
- panoramica degli strumenti disponibili (con particolare attenzione a GitHub Copilot);
- demo guidate di utilizzo in IDE/VS Code;
- buone pratiche, limiti e criticità nell’uso dell’AI nello sviluppo software.
